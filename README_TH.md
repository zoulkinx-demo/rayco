# Ray & Co, Vision Lab — คู่มือแก้ไขเว็บไซต์

## การปรับปรุงเวอร์ชัน 14

- ใช้ Glass UI ที่เห็นชัดกับ Catalog ทั้งแถบตัวกรอง ช่องค้นหา ตัวเลือกเรียงลำดับ และการ์ดสินค้า
- เพิ่มพื้นหลังแสงและวงเลนส์ด้านหลัง Catalog เพื่อให้มองเห็นความโปร่งใสและการเบลอของกระจกจริง
- Gallery บรรยากาศร้านและรีวิวลูกค้ากดซ้าย–ขวาวนต่อได้ไม่สิ้นสุด รวมถึงการลากและปัดบนมือถือ
- คำว่า `Distinctly.` ใน Hero ใช้สีทองแชมเปญไล่เฉดตามลำดับสายตาแบบ Luxury
- Header ยังคงเป็นแบบเรียบ ไม่มีกรอบแคปซูลซ้อน
- Animation วง Optical ยึดโครงสร้าง จังหวะ และพฤติกรรมจากเวอร์ชัน 8
- รีวิวทุกการ์ดมี Animation ต่อเนื่องแบบเหลื่อมจังหวะ ไม่ได้ทำงานเฉพาะใบแรก
- ฟีเจอร์ภาพสินค้าหลายมุม Best Seller และ Animation อื่นยังอยู่ครบ

โปรเจกต์นี้เป็น HTML, CSS และ JavaScript ปกติ เปิดและแก้ไขได้ด้วย VS Code หรือโปรแกรมแก้ไขข้อความทั่วไป

## เปิดดูเว็บไซต์

ดับเบิลคลิก `index.html` หรือเปิดผ่าน Live Server ใน VS Code

## จุดที่แก้บ่อย

- `js/config.js` — โลโก้, LINE, ที่อยู่, เบอร์โทร, Google Maps, Catalog, ราคา, รีวิว, TikTok, รายชื่อแบรนด์ และ Gallery
- `index.html` — ข้อความและโครงสร้างแต่ละส่วนของหน้าเว็บ
- `css/style.css` — สี ฟอนต์ ระยะห่าง ขนาด และ Animation
- `js/main.js` — สไลด์ Hero, จุดเลือกภาพ, Catalog, ซูมสินค้า, Gallery, เมนู, ตัวกรอง, FAQ และการโต้ตอบ
- `assets/images/` — รูป Hero, รูป Editorial, รูปสินค้า และรูปบรรยากาศร้าน

## เปลี่ยนโลโก้หลัก

โลโก้หลักอยู่ที่ `assets/images/branding/rayco-main-logo.png` และถูกใช้ใน Header, Footer และหน้า 404 แล้ว หากต้องการเปลี่ยนโลโก้ในหน้าเว็บไซต์ ให้แทนไฟล์เดิมหรือแก้ `brand.logo` ใน `js/config.js` โดยแนะนำภาพแนวนอนพื้นดำ อัตราส่วนใกล้เคียง 3.4:1

Favicon แบบใหม่เป็นสัญลักษณ์ดวงตา–วงเลนส์สีทองบนพื้นดำ อยู่ที่ `favicon.ico` พร้อมไฟล์ PNG ขนาด 16, 32 และ Apple Touch Icon ใน `assets/images/branding/`

## แก้ไขรีวิวจากลูกค้า

เปิด `js/config.js` แล้วแก้รายการใน `reviews` สามารถเพิ่ม ลบ หรือเรียงใหม่ได้ โดยใช้ข้อมูลดังนี้

- `name` ชื่อลูกค้าที่อนุญาตให้เผยแพร่
- `initials` อักษรย่อที่แสดงในวงกลม
- `rating` คะแนน 1–5 ดาว
- `service` สินค้าหรือบริการที่ใช้
- `text` เนื้อหารีวิว

รีวิวที่ให้มาเป็นข้อมูลตัวอย่างสำหรับจัดหน้า จึงมีป้ายกำกับบนเว็บไซต์ กรุณาเปลี่ยนเป็นรีวิวจริงและตั้ง `reviewSummary.isSample: false` ก่อนเผยแพร่ สามารถแก้คะแนนรวมที่ `reviewSummary.average`

## ภาพส่วน Brand Promise และ Editorial

## แก้ไข Catalog สินค้า

เปิด `js/config.js` แล้วแก้รายการใน `products` (ภายในมี 12 รายการและรูปตัวอย่างสำหรับจัดหน้า ควรเปลี่ยนชื่อ รายละเอียด และรูปให้ตรงกับสินค้าจริงก่อนเผยแพร่)

- `code` รหัสสินค้า
- `name` ชื่อรุ่น
- `description` คำอธิบายสั้น
- `category` ใช้ `signature`, `optical` หรือ `sunglasses`
- `badge` ป้ายสีดำบนรูป เช่น `SIGNATURE` หรือ `OPTICAL`
- `collection` ชื่อคอลเลกชันที่แสดงเหนือชื่อรุ่น
- `price` ใส่ราคาปัจจุบัน เช่น `'฿2,990'`, `'เริ่มต้น ฿1,990'` หรือ `'สอบถามราคา'`
- `oldPrice` ใส่ราคาเดิมเมื่อต้องการแสดงราคาขีดฆ่า หรือใส่ `''` เพื่อซ่อน
- `images` ใส่ได้หลายรูป เช่น `['assets/images/products/front.jpg', 'assets/images/products/side.jpg']`

รูปแรกใน `images` จะเป็นรูปหน้าปกของการ์ด เมื่อกดรูปจะเปิดหน้าต่างขยาย สามารถซูมด้วยปุ่ม `＋/−`, หมุนล้อเมาส์, ดับเบิลคลิก และลากภาพหลังซูมได้ หากยังไม่มีรูป ระบบจะแสดงช่อง `ADD PRODUCT PHOTO` โดยไม่สร้างภาพกรอบแว่นจำลอง

### เพิ่มภาพสินค้าหลายมุม

สินค้าแต่ละรุ่นรองรับหลายภาพใน `images` เช่น

```js
images: [
  'assets/images/products/model-front.webp',
  'assets/images/products/model-side.webp',
  'assets/images/products/model-detail.webp',
  'assets/images/products/model-on-face.webp'
]
```

- ภาพแรกเป็นภาพหน้าปกบนการ์ด
- ภาพทั้งหมดจะแสดงเป็น Thumbnail ในหน้าต่างสินค้า
- ลูกศรภายในภาพ, ปุ่มลูกศรบนคีย์บอร์ด และการปัดซ้าย–ขวาบนมือถือใช้เปลี่ยนมุมภาพ
- `Shift + ←/→` และปุ่มลูกศรด้านนอกหน้าต่างใช้เปลี่ยนไปสินค้ารุ่นก่อนหน้า/ถัดไป
- หากมีภาพเดียว ระบบจะซ่อนตัวนับและปุ่มเปลี่ยนมุมอัตโนมัติ

### ป้ายสินค้าขายดี

เพิ่ม `bestSeller: true` ในข้อมูลสินค้าที่ต้องการให้แสดงป้าย `BEST SELLER / สินค้าขายดี` หากต้องการซ่อนให้เปลี่ยนเป็น `false` หรือลบค่านี้ออก

Catalog ถูกวางไว้ช่วงล่างของหน้า หลังส่วน Story, จุดเด่น, แบรนด์, Gallery และขั้นตอนรับคำปรึกษา เพื่อให้ลูกค้าได้สำรวจและทำความรู้จัก Ray & Co ก่อนเลือกสินค้า หากต้องการปรับขนาดการ์ด ให้แก้ `.collection-grid`, `.product-media` และ `.product-meta` ใน `css/style.css`

ราคาที่ใส่มาในโปรเจกต์เป็น “ราคาตัวอย่างสำหรับจัดหน้า” ต้องเปลี่ยนให้ตรงกับราคาจริงก่อนเผยแพร่ ราคาแสดงทั้งบนการ์ดและหน้าต่างขยายสินค้า โดยใช้ป้าย “ราคา” เส้นทอง และตัวเลขแบบหนาที่อ่านง่ายเพื่อสร้างลำดับสายตาแบบ Luxury ไม่ใช่ป้ายลดราคา

## เพิ่มวิดีโอจาก TikTok

เปิด `js/config.js` แล้วเพิ่มลิงก์ใน `tiktokVideos` โดยใช้ลิงก์แบบเต็มที่มี `/video/ตัวเลข`

```js
tiktokProfileUrl: 'https://www.tiktok.com/@ชื่อบัญชี',
tiktokVideos: [
  { url: 'https://www.tiktok.com/@ชื่อบัญชี/video/1234567890123456789', title: 'แนะนำกรอบแว่นรุ่นใหม่' },
  { url: 'https://www.tiktok.com/@ชื่อบัญชี/video/9876543210987654321', title: 'วิธีเลือกแว่นให้เข้ากับรูปหน้า' }
],
```

- เพิ่มหรือลบคลิปได้โดยแก้รายการใน `tiktokVideos`
- ใช้เพียงข้อความลิงก์ก็ได้ เช่น `'https://www.tiktok.com/@ชื่อบัญชี/video/1234567890123456789'`
- ลิงก์ย่อแบบ `vt.tiktok.com` หรือ `vm.tiktok.com` ต้องเปิดลิงก์นั้นก่อน แล้วคัดลอก URL แบบเต็มจากแถบที่อยู่
- หาก `tiktokVideos` เป็น `[]` หน้าเว็บจะซ่อนส่วน TikTok และเมนู TikTok อัตโนมัติ
- บนคอมพิวเตอร์ วิดีโอทั้ง 4 คลิปจะแสดงในแถวเดียวด้วยขนาดกะทัดรัด ส่วนแท็บเล็ตและมือถือจะแสดงแบบ 2 คอลัมน์เพื่อไม่ให้ล้นหน้าจอ
- วิดีโอจะไม่เล่นอัตโนมัติ และโหลดเมื่อผู้ใช้เลื่อนมาถึงบริเวณนั้น เพื่อลดการใช้ข้อมูล

## แก้ไขส่วน “ทำไมต้องเลือกเรา”

ข้อความทั้ง 9 ช่องอยู่ใน `index.html` ภายในส่วน `id="whyUs"` สามารถแก้หัวข้อ คำอธิบาย และสัญลักษณ์ได้โดยตรง

ข้อความเริ่มต้นหลีกเลี่ยงคำอ้างที่ยังไม่ได้ยืนยัน เช่น “ตัวแทนจำหน่ายอย่างเป็นทางการ”, การรับประกัน และการจัดส่งทั่วประเทศ หากร้านมีบริการดังกล่าวจริงจึงค่อยแก้ข้อความภายหลัง

## แก้ไขแถบข้อความเคลื่อนที่

คำว่า `Elegance`, `Confidence`, `Precision`, `Innovation` และ `Authenticity` อยู่ใน `index.html` ภายใน `marquee-group` จำนวน 2 ชุด ต้องแก้ทั้งสองชุดให้เหมือนกันเพื่อให้เลื่อนวนต่อเนื่อง

ความเร็วกำหนดที่ `.marquee-track` ใน `css/style.css` ค่าเริ่มต้นคือ `28s` ยิ่งตัวเลขมากยิ่งเคลื่อนที่ช้าลง

## ปุ่ม LINE แบบมีออร่า

ออร่าสีเขียวใช้กับปุ่ม LINE หลัก, ปุ่มเมนู และปุ่มลอย กำหนดด้วย `@keyframes lineAura` ใน `css/style.css` สามารถปรับความเร็วได้ที่ค่า `2.2s`

## แก้ไขรายชื่อแบรนด์

เปิด `js/config.js` แล้วเพิ่ม ลบ หรือเรียงชื่อใหม่ใน `brands` ให้ตรงกับแบรนด์ที่ร้านมีจำหน่ายจริง

หน้าเว็บใช้คำว่า “แบรนด์ที่เราจำหน่าย” และไม่ได้อ้างว่าเป็นตัวแทนจำหน่ายอย่างเป็นทางการ หากต้องการใช้คำดังกล่าวควรตรวจสอบสิทธิ์ของแต่ละแบรนด์ก่อน

## เพิ่มภาพ Gallery บรรยากาศร้าน

1. นำภาพจริงไปไว้ใน `assets/images/showroom/`
2. เปิด `js/config.js`
3. ใส่พาธใน `gallery` เช่น `assets/images/showroom/showroom-01.jpg`
4. แก้ `title` และ `alt` ให้ตรงกับภาพ

แนะนำภาพแนวตั้งหรือ 4:5 ความกว้างอย่างน้อย 1200 px หาก `image` ยังว่าง ระบบจะแสดงพื้นที่ตัวอย่างแทนและจะไม่ใช้ภาพร้านสมมติ

เวอร์ชันนี้มีภาพบรรยากาศร้าน 16 ภาพใน `assets/images/showroom/` และเชื่อมกับ `gallery` ใน `js/config.js` แล้ว สามารถเปลี่ยนชื่อไฟล์ ชื่อภาพ ข้อความอธิบาย ลำดับ หรือลบ/เพิ่มรายการได้จากอาร์เรย์นี้ตามเดิม

## Animation แบบ Luxury Motion

ส่วน Brand Story, Decode the Name, Brand Values, Style Journal และขั้นตอนบริการจะเริ่มเคลื่อนไหวอย่างนุ่มนวลเมื่อเลื่อนมาถึง โดยใช้เส้น แสง และสีทองตาม Theme เดิม พื้นหลังของ Decode the Name และ Brand Values มีวง Optical และลำแสงเคลื่อนไหวต่อเนื่อง ส่วนรีวิวมีวงแสงเคลื่อนช้า ๆ หากอุปกรณ์เปิด Reduce Motion ระบบจะปิดการเคลื่อนไหวที่ไม่จำเป็นให้อัตโนมัติ

ดาวรีวิวจะแสดงขนาดใหญ่ขึ้นและปรากฏเรียงทีละดวง การ์ดสินค้าจะเปิดเข้ามาทีละใบพร้อมแสงทองและเอฟเฟกต์เอียงเล็กน้อย ส่วนแถบบริการทั้ง 3 ช่องใช้แสงต่อเนื่องจังหวะเดียวกันเพื่อลดอาการเคลื่อนไหวสะดุด

## Glass UI ใน Catalog

Glass UI ใช้กับส่วน Catalog โดยตรง ทั้งแถบตัวกรอง ช่องค้นหา ตัวเลือกเรียงลำดับ การ์ดสินค้า และชั้นข้อมูลใต้ภาพ พื้นหลังของ Catalog มีแสงไล่ระดับและวงเลนส์เพื่อให้เห็นความโปร่งใส การเบลอ และขอบสะท้อนแสงของกระจกชัดเจน ส่วน Header ยังคงเป็นพื้นเรียบตามดีไซน์เวอร์ชัน 13

Gallery บรรยากาศร้านและรีวิวลูกค้าใช้แถบเลื่อนแบบวงต่อเนื่อง จากรายการสุดท้ายกดถัดไปจะกลับรายการแรก และจากรายการแรกกดย้อนกลับจะไปรายการสุดท้าย สามารถใช้ปุ่มลูกศรบนคีย์บอร์ด ลากด้วยเมาส์ หรือปัดบนมือถือได้

Hero มีแถบความน่าเชื่อถือ `ของแท้ 100%`, `มีหน้าร้านจริง` และ `ตัวแทนจำหน่าย 18+ แบรนด์` อยู่ใต้ปุ่มหลัก สามารถแก้ข้อความได้โดยตรงใน `index.html` บริเวณ `hero-proof`

## ลิงก์โซเชียลใน Footer

แก้ลิงก์ Facebook, Instagram, TikTok และ LINE ได้จาก `socialLinks` ใน `js/config.js` หากใส่ค่าว่าง `''` ไอคอนช่องทางนั้นจะถูกซ่อนอัตโนมัติ Facebook และ Instagram ที่ให้มาเป็นลิงก์ตัวอย่าง กรุณาเปลี่ยนเป็นบัญชีจริงก่อนเผยแพร่

## เปลี่ยนฟอนต์

ฟอนต์หลักถูกกำหนดใน `css/style.css`

- `--font-display` สำหรับหัวข้อและข้อความสไตล์ Luxury
- `--font-body` สำหรับเนื้อหา เมนู และปุ่ม
- `--font-price` สำหรับตัวเลขราคาโดยเฉพาะ เน้นความคมชัดและอ่านง่ายบนมือถือ

เว็บโหลด Cormorant Garamond, Noto Serif Thai และ Noto Sans Thai ผ่าน Google Fonts หากไม่มีอินเทอร์เน็ต ระบบจะใช้ฟอนต์สำรองอัตโนมัติ

## เปลี่ยนรูป Hero

นำรูปใหม่ใส่ใน `assets/images/` แล้วแก้ค่า `src` ของแท็กที่มี class `hero-slide` ใน `index.html`

แนะนำให้ใช้ไฟล์ WebP แนวนอน ความกว้างประมาณ 1920 px เพื่อให้เว็บโหลดเร็ว

## สีหลัก

แก้ตัวแปรสีที่ส่วน `:root` ด้านบนของ `css/style.css`

- `--paper` สีขาว
- `--ink` และ `--black` สีดำ
- `--gold` สีทอง
- `--line-green` สีเขียวของปุ่ม LINE

ส่วนแบรนด์และส่วน “ทำไมต้องเลือกเรา” ใช้พื้นครีมเดียวกัน `#eee7d8` เพื่อไม่ให้เห็นรอยต่อของสี หากต้องการเปลี่ยน ให้แก้กฎ `.brand-showcase,.why-us` ใน `css/style.css`

## ก่อนนำขึ้น GitHub Pages

อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดโดยรักษาโครงสร้างเดิม และให้ `index.html` อยู่ที่หน้าแรกของ repository

## สิ่งที่เพิ่มในเวอร์ชัน 16

- ใช้โลโก้ `Ray & Co, VISION LAB` ล่าสุดจากไฟล์ `assets/images/branding/ray-co-vision-lab-logo-v2.png` ใน Header, Footer, หน้า 404 และภาพแชร์เว็บไซต์
- เพิ่มพื้นหลัง Catalog แบบหลายชั้น: แสง Champagne, วงเลนส์, แสงกวาด และประกายที่เคลื่อนอย่างนุ่มนวล
- ปรับหน้าต่างรายละเอียดสินค้าเป็น Glass UI โทน Charcoal–Champagne ที่สว่างและเห็นมิติกระจกชัดขึ้น
- ยกเลิกแสงวิบวับที่วิ่งซ้ำบนข้อความ `We shape your perspective.` และเปลี่ยนเป็นสีทองคงที่เพื่อให้อ่านง่ายขึ้น โดยยังคง Animation พื้นหลังและการปรากฏของเนื้อหาไว้
- รองรับ `prefers-reduced-motion` เพื่อหยุด Animation ที่ไม่จำเป็นสำหรับผู้ใช้ที่ตั้งค่าลดการเคลื่อนไหว

## เมนูสองภาษา

เมนูหลักและเมนูมือถือแสดงภาษาอังกฤษกับภาษาไทยคู่กัน โดยข้อความภาษาอังกฤษใช้ class `nav-en` และภาษาไทยใช้ class `nav-th` สามารถแก้ชื่อแต่ละเมนูได้โดยตรงใน `index.html`

## ข้อมูลตัวอย่างส่วนติดต่อ

ข้อมูลที่อยู่ เบอร์โทร และเวลาเปิดร้านใน `js/config.js` เป็นข้อมูลตัวอย่างเพื่อแสดงภาพรวมของหน้าเว็บ โดยกำหนด `isSample: true` ไว้เพื่อไม่ให้ระบบเปิดแผนที่จากที่อยู่สมมติ

เมื่อพร้อมใช้ข้อมูลจริง:

1. เปลี่ยน `address`, `phone` และ `openingHours`
2. ใส่ `mapOpenUrl` หรือ `mapEmbedUrl` หากมี
3. เปลี่ยน `isSample: true` เป็น `isSample: false`

## Sitemap, Favicon และหน้า 404

- `favicon.ico` คือสัญลักษณ์ดวงตา–วงเลนส์สีทองบนพื้นดำ และเชื่อมกับ `index.html` และ `404.html` แล้ว
- Brand Story, Brand Promise และ Editorial มี Animation พื้นหลังแบบวงเลนส์ แสง Champagne และประกายละเอียด โดยไม่ให้เอฟเฟกต์วิ่งผ่านข้อความ
- `404.html` ใช้โทนดำ–ทอง–เขียวเดียวกับเว็บไซต์ พร้อมปุ่มกลับหน้าแรกและติดต่อ LINE
- `sitemap.xml` มีหน้าแรกของเว็บไซต์ เนื่องจากเว็บไซต์นี้เป็นเว็บไซต์หน้าเดียว
- ก่อนเผยแพร่ ให้เปิด `sitemap.xml` แล้วเปลี่ยน `https://www.your-domain.com/` เป็น URL จริง รวมโฟลเดอร์ repository หากใช้ GitHub Pages เช่น `https://ชื่อผู้ใช้.github.io/ชื่อ-repository/`
