# Ray & Co, Vision Lab — เว็บไซต์ร้านแว่นตา

โฟลเดอร์นี้คือเว็บไซต์ฉบับสมบูรณ์ของคุณ เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (ดับเบิลคลิกได้เลย) เพื่อดูเว็บไซต์ทันที ไม่ต้องติดตั้งอะไรเพิ่ม

> **อัปเดตล่าสุด:** เว็บไซต์โหลดจากไฟล์ `css/style.css` และ `js/script.js` โดยตรง (ไม่มีเวอร์ชัน minify แยกต่างหากแล้ว) เพื่อให้แก้ไขไฟล์แล้วเห็นผลทันทีเสมอ พร้อมเพิ่ม: ป้ายความน่าเชื่อถือใน Hero, จำนวนสินค้าต่อแท็บ, ตัวเรียงสินค้าตามราคา/ชื่อ, และแก้ไขสีตัวอักษรบางจุดให้อ่านง่ายขึ้นตามมาตรฐาน WCAG

```
site/
├── index.html          ← หน้าเว็บหลัก (แก้ข้อความ/เนื้อหาที่นี่)
├── order-guide.html     ← หน้า "วิธีการสั่งซื้อ"
├── 404.html              ← หน้าแสดงผลเมื่อลิงก์ผิด/ไม่พบหน้า
├── favicon.ico            ← ไอคอนแท็บเบราว์เซอร์
├── robots.txt              ← ไฟล์ควบคุมการเก็บข้อมูลของ Google
├── sitemap.xml              ← แผนผังเว็บไซต์สำหรับ SEO
├── css/style.css        ← สี, ฟอนต์, ดีไซน์ทั้งหมด
├── js/script.js         ← สไลด์โชว์, เมนู, ค้นหา, ฟิลเตอร์สินค้า, แกลเลอรีสินค้า, LINE link
├── articles/             ← หน้าบทความแบบเต็ม 3 หน้า
│   ├── style-guide.html
│   ├── care-guide.html
│   └── trend-2026.html
└── assets/
    ├── logo/             ← โลโก้ร้าน + favicon ทุกขนาด + og-image.jpg
    ├── products/          ← รูปสินค้า 12 ชิ้น (product-01.jpg ... product-12.webp)
    ├── shop/               ← รูปภายในร้าน 18 ภาพ (shop-01.jpg ... shop-18.jpg)
    └── brands/              ← โลโก้แบรนด์ที่จำหน่าย (ไฟล์ตัวอย่าง รอแทนที่ด้วยโลโก้จริง)
```

## 🟢 สิ่งแรกที่ต้องแก้ก่อนใช้งานจริง: LINE ID

เว็บไซต์นี้ **ไม่มีระบบสั่งซื้อ/ตะกร้าสินค้า** ตามที่ขอ — ทุกปุ่ม "สั่งซื้อ" หรือ "สนใจสินค้า" จะลิงก์ไปที่ LINE ของร้านแทน ตอนนี้ใช้ ID ตัวอย่าง `@rayandco` อยู่ ให้แก้เป็น LINE OA จริงของร้านคุณที่ไฟล์เดียว:

เปิดไฟล์ `js/script.js` แล้วแก้บรรทัดนี้ที่ด้านบนสุด:

```js
const CONFIG = {
  lineUrl: "https://line.me/R/ti/p/@rayandco"   // ← แก้ตรงนี้เป็นลิงก์ LINE OA จริงของร้าน
};
```

แก้ที่เดียวจบ — ปุ่ม LINE ทุกปุ่มทั่วทั้งเว็บไซต์ (ปุ่มลอยมุมขวาล่าง, ปุ่มในสินค้าแต่ละชิ้น, ปุ่มในส่วนติดต่อ) จะอัปเดตอัตโนมัติ

> วิธีหาลิงก์ LINE OA ของร้าน: เข้า LINE Official Account Manager → เลือกร้านของคุณ → เมนู "การตั้งค่า" → "โปรไฟล์บัญชี" → คัดลอก URL หรือ LINE ID

## ✏️ แก้ข้อมูลร้าน (ที่อยู่ / เบอร์โทร / เวลาทำการ)

เปิดไฟล์ `index.html` ค้นหาคำว่า `[ใส่ที่อยู่ร้าน` และ `[0XX-XXX-XXXX]` (มีทั้งหมด 2 จุด: ส่วน "Visit Us" และส่วน Footer ด้านล่างสุด) แล้วแทนที่ด้วยข้อมูลจริงของร้าน

## 🖼️ แก้ไข/เพิ่มรูปสินค้า

1. เพิ่มไฟล์รูปใหม่ลงในโฟลเดอร์ `assets/products/`
2. เปิด `index.html` ค้นหาส่วน `<!-- Signature -->`, `<!-- Sunglasses -->`, `<!-- Optical -->` ภายใน section `id="collection"`
3. คัดลอกโครงสร้าง `<article class="product-card" data-cat="...">` หนึ่งชุด แล้วแก้:
   - `data-cat` → `signature` / `sun` / `optical` (กำหนดว่าจะให้ขึ้นในแท็บไหน)
   - `src="assets/products/ไฟล์ใหม่ของคุณ.jpg"`
   - ชื่อสินค้าและคำอธิบายสั้นๆ

## 🏬 แก้ไขรูปภายในร้าน (Showroom)

อยู่ใน section `id="showroom"` ในไฟล์ `index.html` — โครงสร้างเหมือนกับสินค้า เพิ่ม/ลบ `<div class="gallery-item">` ได้ตามต้องการ พร้อมเปลี่ยน `assets/shop/...`

## 💰 แก้ไขราคาสินค้า

ราคาที่ใส่ไว้ตอนนี้เป็น **ราคาตัวอย่าง** เท่านั้น ให้แก้เป็นราคาจริงของร้าน — ค้นหา `class="product-price"` ในไฟล์ `index.html` แต่ละชิ้นจะมีโครงสร้างแบบนี้:

```html
<div class="product-price"><span class="now">8,900</span></div>
```

ถ้าต้องการใส่ราคาก่อนลด (ราคาขีดฆ่า) เพิ่ม `<span class="was">10,500</span>` ต่อท้ายได้เลย

## ⭐ แก้ไขส่วน "สินค้าขายดี"

เป็น **สไลด์โชว์เลื่อนอัตโนมัติ** ที่ขึ้นทีละชิ้น (วนลูปไม่มีที่สิ้นสุด ทุก 4.2 วินาที) พร้อมป้าย "สินค้าขายดี" สีทองเด่นชัดและเลขอันดับตัวใหญ่ อยู่ใน section `id="bestsellers"` — เลื่อนเมาส์ไปแตะที่สไลด์จะหยุดเลื่อนอัตโนมัติชั่วคราว ให้ลูกค้าอ่านได้สบายๆ แต่ละสไลด์:
- **คลิกที่รูปภาพ** → เปิดภาพขยาย (Lightbox) ให้ลูกค้าดูสินค้าชัดๆ
- **ปุ่ม "สั่งซื้อทาง LINE"** → ลิงก์ตรงไปที่ไลน์ร้านทันที (สีเขียว LINE)
- **ปุ่ม "ดูรายละเอียด"** → เลื่อนไปหน้าสินค้าทั้งหมด

**เพิ่ม/แก้สินค้าขายดี:** ค้นหา `class="bs-slide"` ในไฟล์ `index.html` คัดลอกโครงสร้างหนึ่งชุดเพื่อเพิ่มสินค้าใหม่ หรือแก้รูป/ชื่อ/ราคา/ยอดขายของสินค้าที่มีอยู่ได้เลย

ตอนนี้บทความมีหน้าเนื้อหาเต็มแล้ว 3 หน้า อยู่ในโฟลเดอร์ `articles/`:

> **หมายเหตุสำคัญ:** หน้าบทความและหน้า `order-guide.html` มีปุ่ม LINE ของตัวเอง (ไม่ได้เชื่อมกับ `CONFIG.lineUrl` ใน `js/script.js`) หากเปลี่ยน LINE ID ของร้าน ต้องแก้ในไฟล์ `articles/*.html` ทั้ง 3 ไฟล์ และ `order-guide.html` ด้วย — วิธีที่เร็วที่สุดคือค้นหาคำว่า `@rayandco` แล้วแทนที่ทั้งหมดทุกไฟล์

## 🏷️ แบรนด์ที่จำหน่าย — ใส่โลโก้จริงได้แล้ว

เปลี่ยนจากตัวอักษรดีไซน์เป็น**รูปภาพโลโก้**แล้ว ตอนนี้ในโฟลเดอร์ `assets/brands/` มีไฟล์ตัวอย่างชั่วคราว (พื้นหลังโปร่งใส เขียนชื่อแบรนด์ด้วยฟอนต์ทั่วไป) รอให้คุณแทนที่ด้วยโลโก้จริง

**วิธีใส่โลโก้จริง:**
1. หาไฟล์โลโก้แบรนด์ที่ร้านคุณเป็นตัวแทนจำหน่ายจริง (ควรขอจากทางแบรนด์/ตัวแทนจำหน่ายโดยตรง หรือใช้จากเว็บไซต์ทางการของแบรนด์นั้นๆ เพื่อความถูกต้องด้านลิขสิทธิ์)
2. บันทึกไฟล์เป็น **PNG พื้นหลังโปร่งใส** ขนาดแนะนำประมาณ 500×220px (หรือสัดส่วนใกล้เคียง)
3. ตั้งชื่อไฟล์ให้ตรงกับที่ใช้อยู่ แล้วนำไปวางทับที่ `assets/brands/` เช่น `ray-ban.png`, `gucci.png`, `dior.png` เป็นต้น (ดูชื่อไฟล์ทั้งหมดได้จากโค้ดในส่วน `class="brand-grid"` ของ `index.html`)
4. ไม่ต้องแก้โค้ด HTML ใดๆ แค่แทนที่ไฟล์รูปในตำแหน่งเดิม ระบบจะแสดงโลโก้ใหม่ทันที

> ไฟล์ตัวอย่างที่ให้มาเป็นเพียงข้อความชื่อแบรนด์ธรรมดา **ไม่ใช่โลโก้ทางการ** ของแบรนด์นั้นๆ สร้างไว้ชั่วคราวเพื่อให้เว็บไซต์ใช้งานได้ก่อน แนะนำให้เปลี่ยนเป็นโลโก้จริงก่อนเปิดใช้งานเว็บไซต์จริง

## 🖼️ แกลเลอรีภาพสินค้าหลายมุม

ตอนนี้การ์ดสินค้าแต่ละชิ้นรองรับภาพได้หลายมุม (มีลูกศรซ้าย-ขวาและจุดบอกตำแหน่งเมื่อ hover) แต่เนื่องจากตอนนี้มีภาพต่อสินค้าแค่มุมเดียว ระบบจึงใช้ภาพเดิมซ้ำ 3 ครั้งไปก่อน เพื่อให้โครงสร้างพร้อมใช้งานทันทีที่มีภาพเพิ่ม

**เพิ่มภาพมุมอื่นๆ ของสินค้าจริง:**
1. เพิ่มไฟล์ภาพมุมต่างๆ ลงใน `assets/products/` เช่น `product-01-side.jpg`, `product-01-back.jpg`
2. เปิด `index.html` ค้นหา `data-images=` ของสินค้านั้น จะเห็นแบบนี้:
   ```html
   data-images="assets/products/product-01.jpg,assets/products/product-01.jpg,assets/products/product-01.jpg"
   ```
3. แก้เป็นภาพจริงแต่ละมุม:
   ```html
   data-images="assets/products/product-01.jpg,assets/products/product-01-side.jpg,assets/products/product-01-back.jpg"
   ```
   ใส่กี่ภาพก็ได้ (คั่นด้วย comma) ระบบจะสร้างจุดบอกตำแหน่งให้อัตโนมัติตามจำนวนภาพ

## 🎵 แก้ไขคลิป TikTok

อยู่ใน section `id="tiktok"` ใช้ลิงก์คลิปจากไฟล์ `tiktok.txt` ที่คุณแนบมาเป็นตัวอย่าง (จากบัญชี @moshi.optic) **แนะนำให้เปลี่ยนเป็นคลิปจริงของร้าน Ray & Co เอง** เมื่อมีคอนเทนต์แล้ว โดยแก้ 2 จุดในแต่ละการ์ด:

```html
<blockquote class="tiktok-embed" cite="https://www.tiktok.com/@ชื่อบัญชีร้าน/video/รหัสคลิป" data-video-id="รหัสคลิป" ...>
```

รหัสคลิป (video ID) คือชุดตัวเลขท้ายลิงก์ TikTok เช่น `7487062070874213650`
อย่าลืมแก้ลิงก์ปุ่ม "ดูเพิ่มเติมบน TikTok" (ตอนนี้เป็น `#`) ให้เป็นลิงก์โปรไฟล์ TikTok จริงของร้านด้วย

## 🗺️ แก้ไข Google Map

อยู่ใน section `id="visit"` ค้นหา `<iframe` ที่มี `src="https://www.google.com/maps?q=Bangkok,Thailand&output=embed"` แล้วแก้ `Bangkok,Thailand` เป็นที่อยู่ร้านจริง เช่น:

```html
src="https://www.google.com/maps?q=42+ถนนสุขุมวิท+คลองตัน+กรุงเทพ&output=embed"
```

ไม่ต้องมี API Key ใดๆ ใช้งานได้ทันที — หรือถ้าต้องการฝังแผนที่แบบที่ปักหมุดร้านแม่นยำ 100% ให้เข้า Google Maps → ค้นหาร้าน → กด "แชร์" → "ฝังแผนที่" (Embed a map) → คัดลอกโค้ด `<iframe>` มาแทนที่อันเดิม

## 🎨 โลโก้ร้าน

ใช้โลโก้จริงของคุณแล้วทั่วทั้งเว็บไซต์ (Header, Footer, หน้า 404) ระบบสร้างไฟล์ให้อัตโนมัติจากโลโก้ต้นฉบับที่ส่งมา:
- `assets/logo/logo-white.png` — โลโก้เวอร์ชันสีขาว+ทอง สำหรับพื้นหลังเข้ม (ใช้ใน Header/Footer)
- `assets/logo/logo-original.png` — โลโก้สีดำ+ทองต้นฉบับ สำหรับพื้นหลังสว่าง (เผื่อใช้งานในอนาคต เช่น เอกสาร/นามบัตร)
- `assets/logo/favicon.ico`, `favicon-16.png`, `favicon-32.png`, `favicon-192.png`, `favicon-512.png`, `apple-touch-icon.png` — ไอคอนสำหรับแท็บเบราว์เซอร์และมือถือ

**ถ้าต้องการเปลี่ยนโลโก้ในอนาคต:** แทนที่ไฟล์ในโฟลเดอร์ `assets/logo/` ด้วยชื่อไฟล์เดิม ไม่ต้องแก้โค้ด

## 🌐 ไฟล์ SEO และมาตรฐานเว็บไซต์

| ไฟล์ | หน้าที่ |
|---|---|
| `favicon.ico` + ไฟล์ในโฟลเดอร์ `assets/logo/` | ไอคอนแท็บเบราว์เซอร์ |
| `robots.txt` | บอก Google ว่าอนุญาตให้เก็บข้อมูลหน้าไหนบ้าง |
| `sitemap.xml` | รายการหน้าเว็บทั้งหมดสำหรับ Google |
| `404.html` | หน้าแสดงผลเมื่อลิงก์ผิดหรือไม่พบหน้า |
| Open Graph / Twitter Card meta tags | ทำให้ลิงก์ที่แชร์ไป Facebook/LINE/Twitter ขึ้นรูปภาพและหัวข้อสวยงามอัตโนมัติ (ใช้ภาพ `assets/logo/og-image.jpg`) |

> ⚠️ **สำคัญ:** ไฟล์ทั้งหมดด้านบนอ้างอิงโดเมนตัวอย่าง `https://www.rayandco-visionlab.com` ไว้ก่อน (ยังไม่ใช่โดเมนจริงของร้าน) เมื่อคุณมีโดเมนจริงแล้ว ต้องค้นหาแล้วแทนที่ข้อความนี้ทั้งหมดในไฟล์ `robots.txt`, `sitemap.xml`, และในทุกไฟล์ `.html` (ส่วน `og:url`, `og:image`, `twitter:image`) ด้วยโดเมนจริงของคุณ ไม่เช่นนั้น Preview เวลาแชร์ลิงก์และ SEO จะยังไม่ทำงานถูกต้อง

## 🎨 โทนสีที่ใช้ (อ้างอิงจากโลโก้ของคุณ)

แก้ไขได้ที่ด้านบนของ `css/style.css` ในส่วน `:root { ... }`

| ตัวแปร | สี | ใช้ที่ไหน |
|---|---|---|
| `--black` | `#0b0b0c` | พื้นหลังเข้ม (Hero, Footer, Philosophy) |
| `--gold` | `#b58e5c` | สีทองหลัก (ปุ่ม, เส้นคั่น, ไอคอน) |
| `--gold-bright` | `#d9b579` | สีทองสว่าง (hover, ตัวเน้น) |
| `--cream` | `#f3efe7` | พื้นหลังโทนสว่าง |
| `--ink` | `#1e1b17` | สีตัวอักษรบนพื้นสว่าง |

## 🌐 วิธีนำเว็บไซต์ขึ้นออนไลน์ (Hosting)

โฟลเดอร์นี้เป็น static site (HTML/CSS/JS ล้วน) — อัปโหลดได้ง่ายๆ กับบริการฟรีเหล่านี้:
- **Netlify** (netlify.com) — ลากโฟลเดอร์ทั้งหมดไปวางได้เลย
- **Vercel** (vercel.com)
- **GitHub Pages**
- หรือใช้ hosting ปกติที่รองรับไฟล์ static (อัปโหลดทั้งโฟลเดอร์ผ่าน FTP)

ไม่ต้องมี server, database หรือ backend ใดๆ

## ⚠️ หมายเหตุ

- โซเชียลไอคอนในหน้า Footer เป็นสีตามแบรนด์จริงแล้ว (Facebook สีฟ้า, Instagram ไล่สี, TikTok ดำ, LINE เขียว) แต่ Facebook/Instagram/TikTok ยังเป็นลิงก์ตัวอย่าง `#` — แก้เป็นลิงก์เพจจริงของร้านได้ในไฟล์ `index.html` ค้นหาคำว่า `aria-label="Facebook"` เป็นต้น (LINE ลิงก์ให้อัตโนมัติตาม `CONFIG.lineUrl` แล้ว)
- ราคาสินค้า, ตัวเลขยอดขาย, และเนื้อหาบทความทั้งหมดเป็น **ข้อมูลตัวอย่าง** สำหรับเดโม โปรดแก้ให้ตรงกับข้อมูลจริงก่อนเปิดใช้งาน
- Google Map ใช้ที่อยู่ตัวอย่าง "Bangkok, Thailand" อยู่ — ต้องแก้เป็นที่อยู่ร้านจริงตามวิธีด้านบน
- คลิป TikTok ที่ฝังไว้เป็นคลิปตัวอย่างจากบัญชี @moshi.optic (ไฟล์ที่คุณแนบมา) แนะนำให้เปลี่ยนเป็นคลิปของร้านคุณเองเมื่อมีคอนเทนต์
- รีวิวลูกค้าในส่วน Testimonials เป็น**ตัวอย่างสมมติทั้งหมด** ต้องเปลี่ยนเป็นรีวิวจริงก่อนเปิดใช้งาน (มีข้อความกำกับไว้บนเว็บไซต์แล้วว่าเป็นตัวอย่าง)
- โลโก้แบรนด์ใน `assets/brands/` ยังเป็นไฟล์ข้อความชั่วคราว ไม่ใช่โลโก้ทางการของแบรนด์นั้นๆ
- ลิงก์ Open Graph / robots.txt / sitemap.xml ทั้งหมดอ้างอิงโดเมนตัวอย่างไว้ก่อน ต้องแก้เป็นโดเมนจริงเมื่อพร้อมเปิดใช้งาน (ดูหัวข้อ "ไฟล์ SEO และมาตรฐานเว็บไซต์" ด้านบน)
- รูปภาพทั้งหมดถูกบีบอัดให้เหมาะกับเว็บแล้ว (ขนาดรวมประมาณ 5MB)
- เว็บไซต์รองรับมือถือ/แท็บเล็ต/เดสก์ท็อป (Responsive) และมีปุ่ม LINE ลอยติดหน้าจอตลอดการเลื่อนดู
